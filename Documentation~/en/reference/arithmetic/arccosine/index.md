# `Arccosine`

## Purpose

Compute inverse cosine.

## Key inputs / outputs

- Inputs: `a` (numeric).
- Outputs: numeric result in radians.

## Success / Failure semantics

- Success for domain-valid values.
- Failure when input is out-of-domain.

## Important limitations

- Domain restrictions follow `Mathf.Acos`.

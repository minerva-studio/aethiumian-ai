# `Arctangent2`

## Purpose

Compute inverse tangent with two inputs.

## Key inputs / outputs

- Inputs: `a`, `b`.
- Outputs: numeric result in radians.

## Success / Failure semantics

- Success for valid inputs.

## Important limitations

- Input must be numeric.

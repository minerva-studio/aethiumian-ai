# `Magnitude`

## Purpose

Compute vector magnitude.

## Key inputs / outputs

- Inputs: `a` (vector).
- Outputs: scalar magnitude.

## Success / Failure semantics

- Success for Vector2/Vector3/Vector4 inputs.

## Important limitations

- Unsupported scalar types fail.

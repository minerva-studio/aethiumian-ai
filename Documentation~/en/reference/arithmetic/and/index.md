# `And`

## Purpose

Logical AND for two booleans.

## Key inputs / outputs

- Inputs: `a`, `b` (bool).
- Outputs: bool.

## Success / Failure semantics

- Returns `a && b`.

## Important limitations

- Inputs must be bool.

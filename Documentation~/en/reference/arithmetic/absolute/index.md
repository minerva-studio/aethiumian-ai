# `Absolute`

## Purpose

Compute absolute value for numeric input.

## Key inputs / outputs

- Inputs: `a` (`VariableField` numeric).
- Outputs: `result` (`VariableField`) with absolute value.

## Success / Failure semantics

- Success for valid numeric input.
- Failure when input is non-numeric.

## Important limitations

- Numeric-only support.

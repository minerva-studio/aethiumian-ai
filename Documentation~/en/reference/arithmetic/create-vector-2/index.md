# `CreateVector2`

## Purpose

Build a `Vector2` from numeric components.

## Key inputs / outputs

- Inputs: `x`, `y`.
- Outputs: `vector` (`VariableReference<Vector2>`).

## Success / Failure semantics

- Success when output vector reference is valid.

## Important limitations

- Missing components default to `0`.

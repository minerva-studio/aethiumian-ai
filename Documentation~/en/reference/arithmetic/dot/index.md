# `Dot`

## Purpose

Compute dot product.

## Key inputs / outputs

- Inputs: `a`, `b` (`Vector2`/`Vector3`).
- Outputs: scalar result.

## Success / Failure semantics

- Success when vector dimensions match.

## Important limitations

- Mixed vector dimensions fail.

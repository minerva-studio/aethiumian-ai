# `Copy`

## Purpose

Copy value from one variable field to another variable reference.

## Key inputs / outputs

- Inputs: `from`, `to`.
- Outputs: copied target value.

## Success / Failure semantics

- Success when copy is accepted by destination.

## Important limitations

- Type compatibility applies.

# `Cross`

## Purpose

Compute cross product.

## Key inputs / outputs

- Inputs: `a`, `b` (`Vector3`).
- Outputs: cross product vector.

## Success / Failure semantics

- Success for valid vector inputs.

## Important limitations

- Mixed dimensions are not accepted.

# `Or`

## Purpose

Logical OR for two booleans.

## Key inputs / outputs

- Inputs: `a`, `b` (bool).
- Outputs: bool.

## Success / Failure semantics

- Returns `a || b`.

## Important limitations

- Bool input only.

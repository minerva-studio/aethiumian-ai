# `Compare`

## Purpose

Compare two numeric values by selected mode.

## Key inputs / outputs

- Inputs: `a`, `b` (numeric), `Mode`.
- Outputs: bool result.

## Success / Failure semantics

- Returns comparison result.

## Important limitations

- Non-numeric input is unsupported.

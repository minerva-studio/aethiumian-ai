# `Random`

## Purpose

Generate random scalar/vector values.

## Key inputs / outputs

- Inputs: `type`, `min`, `max`, `result`, `randomSourceOverride`.
- Outputs: randomized `result`.

## Success / Failure semantics

- Success when required inputs match result type.

## Important limitations

- Result type determines numeric or vector output behavior.

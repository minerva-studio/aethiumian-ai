# `Divide`

## Purpose

Divide two values.

## Key inputs / outputs

- Inputs: `a`, `b` (numeric).
- Outputs: numeric result.

## Success / Failure semantics

- Success for valid numeric values.
- Failure when divisor is zero or invalid type.

## Important limitations

- Numeric domain check is type dependent.

# `Add`

## Purpose

Add two values or concatenate with strings.

## Key inputs / outputs

- Inputs: `a`, `b`.
- Outputs: `result`.

## Success / Failure semantics

- Success when inputs are compatible and operation is valid.
- Failure for unsupported type combinations.

## Important limitations

- Boolean is not valid input.

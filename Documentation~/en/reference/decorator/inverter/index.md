# `Inverter`

## Purpose

Invert a child node's boolean result.

## Key inputs / outputs

- Inputs: `node` (`TreeNode`).
- Outputs: none.

## Success / Failure semantics

- True becomes false, false becomes true.

## Important limitations

- The child result must be boolean-completable.

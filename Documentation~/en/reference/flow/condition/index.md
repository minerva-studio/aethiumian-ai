# `Condition`

## Purpose

Branch between two nodes by a boolean condition.

## Key inputs / outputs

- Inputs: `condition` (`TreeNode`), `trueNode` (`TreeNode`), `falseNode` (`TreeNode`).
- Outputs: none.

## Success / Failure semantics

- Returns `true` or `false` based on the selected branch return.

## Important limitations

- Both branch nodes must be valid and reachable in tree graph.

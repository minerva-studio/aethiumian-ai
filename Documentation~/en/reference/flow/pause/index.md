# `Pause`

## Purpose

Pause tree execution at the current point.

## Key inputs / outputs

- Inputs: none.
- Outputs: none.

## Success / Failure semantics

- The behavior tree enters paused state when this node is executed.

## Important limitations

- This is an explicit stop; resume depends on external control flow.

# `Restart`

## Purpose

Reload the currently running behaviour tree.

## Key inputs / outputs

- Inputs: none.
- Outputs: none.

## Success / Failure semantics

- Success when the host tree is reloaded and previous stack is replaced.

## Important limitations

- No direct return value is propagated to parent.

# `Yield`

## Purpose

Yield execution for one frame.

## Key inputs / outputs

- Inputs: none.
- Outputs: none.

## Success / Failure semantics

- First execution yields one frame; second returns success.

## Important limitations

- No stateful child execution is performed by this node.

# `CurrentNodeName`

## Purpose

Read the currently executing node name.

## Key inputs / outputs

- Inputs: none.
- Outputs: string value.

## Success / Failure semantics

- Always succeeds and returns current node name.

## Important limitations

- Exposes runtime stack state only.

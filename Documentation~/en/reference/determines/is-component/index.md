# `IsComponent`

## Purpose

Validate whether a variable is a `Component`.

## Key inputs / outputs

- Inputs: `variable`.
- Outputs: bool.

## Success / Failure semantics

- Returns `true` only for component references.

## Important limitations

- Requires a valid input variable.

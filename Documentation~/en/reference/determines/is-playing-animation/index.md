# `IsPlayingAnimation`

## Purpose

Check whether current animator state matches configured name.

## Key inputs / outputs

- Inputs: `stageName`.
- Outputs: bool.

## Success / Failure semantics

- Returns whether Animator is currently in `stageName`.

## Important limitations

- Requires Animator component on host.

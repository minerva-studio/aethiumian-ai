# `IsComponentOrGameObject`

## Purpose

Validate whether a variable is a component or game object.

## Key inputs / outputs

- Inputs: `variable`.
- Outputs: bool.

## Success / Failure semantics

- Returns `true` for `Component` or `GameObject`.

## Important limitations

- Requires a valid input variable.

# `Position`

## Purpose

Read world position of host AI game object.

## Key inputs / outputs

- Inputs: none.
- Outputs: `Vector3` position.

## Success / Failure semantics

- Always returns host transform position.

## Important limitations

- No explicit validity checks beyond transform existence.

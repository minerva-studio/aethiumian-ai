# Action Nodes

`Action` is the executable base category for logic nodes that can run over time and end with success or failure.

## Available nodes

<a id="await"></a>
### [`Await`](actions/await/index.md)

- Wait for a referenced async task to complete before returning.
- [Details](actions/await/index.md)

<a id="fixedjump"></a>
### [`FixedJump`](actions/fixed-jump/index.md)

- Perform one direct or planner-provided ballistic jump.
- [Details](actions/fixed-jump/index.md)

<a id="fly"></a>
### [`Fly`](actions/fly/index.md)

- Move toward a configured goal through planned aerial waypoints.
- [Details](actions/fly/index.md)

<a id="jump"></a>
### [`Jump`](actions/jump/index.md)

- Move toward a configured goal through planned ballistic jumps.
- [Details](actions/jump/index.md)

<a id="functionaction"></a>
### [`FunctionAction`](actions/function-action/index.md)

- Execute a selected reflected function as an action lifecycle node.
- [Details](actions/function-action/index.md)

<a id="idle"></a>
### [`Idle`](actions/idle/index.md)

- Let the current object slow down to zero velocity.
- [Details](actions/idle/index.md)

<a id="objectaction"></a>
### [`ObjectAction`](actions/object-action/index.md)

- Execute a method on a specific object with action-style completion.
- [Details](actions/object-action/index.md)

<a id="playanimationwait"></a>
### [`PlayAnimationWait`](actions/play-animation-wait/index.md)

- Play an animator state and wait until the state is no longer current.
- [Details](actions/play-animation-wait/index.md)

<a id="scriptstartcoroutine"></a>
### [`ScriptStartCoroutine`](actions/script-start-coroutine/index.md)

- Start a coroutine method on the AI script.
- [Details](actions/script-start-coroutine/index.md)

<a id="sprint"></a>
### [`Sprint`](actions/sprint/index.md)

- Apply force to the AI host for a configured duration.
- [Details](actions/sprint/index.md)

<a id="stop"></a>
### [`Stop`](actions/stop/index.md)

- Decelerate or stop movement with selectable strategies.
- [Details](actions/stop/index.md)

<a id="subtree"></a>
### [`Subtree`](actions/subtree/index.md)

- Execute a referenced behaviour-tree data asset as a nested tree.
- [Details](actions/subtree/index.md)

<a id="waitforanimationend"></a>
### [`WaitForAnimationEnd`](actions/wait-for-animation-end/index.md)

- Wait until a target animation state changes.
- [Details](actions/wait-for-animation-end/index.md)

<a id="waitfordestroy"></a>
### [`WaitForDestroy`](actions/wait-for-destroy/index.md)

- Keep waiting until a referenced Unity object is destroyed.
- [Details](actions/wait-for-destroy/index.md)

<a id="walk"></a>
### [`Walk`](actions/walk/index.md)

- Move toward a configured goal through planned ground traversal.
- [Details](actions/walk/index.md)

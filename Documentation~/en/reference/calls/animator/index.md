# `Animator`

## Purpose

Update Animator parameters or triggers.

## Key inputs / outputs

- Inputs: list of typed parameters with value/parameter mode.
- Outputs: none.

## Success / Failure semantics

- `Success` when parameters are applied.
- `Failed` when Animator component is missing.

## Important limitations

- Host object requires an Animator component.

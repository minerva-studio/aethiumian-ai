# `SetObjectValue`

## Purpose

Set fields/properties on a referenced object.

## Key inputs / outputs

- Inputs: `object`, `type`, setter descriptors.
- Outputs: updates target object.

## Success / Failure semantics

- `Success` when base setter succeeds.

## Important limitations

- Target object and member metadata must be compatible.

# `GetObjectValue`

## Purpose

Read value fields from a referenced object.

## Key inputs / outputs

- Inputs: `object`, `type`.
- Outputs: base getter result values.

## Success / Failure semantics

- `Success` when object and reflected members are valid.

## Important limitations

- Requires supported object/field metadata.

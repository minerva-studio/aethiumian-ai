# Call Nodes

`Call` is the base category for non-stateful utility nodes that invoke methods or set/get values.

## Available nodes

<a id="addcomponent"></a>
### [`AddComponent`](calls/add-component/index.md)

- Add a component by type to the selected game object.
- [Details](calls/add-component/index.md)

<a id="addforce"></a>
### [`AddForce`](calls/add-force/index.md)

- Apply a 2D force to the current object.
- [Details](calls/add-force/index.md)

<a id="animator"></a>
### [`Animator`](calls/animator/index.md)

- Update Animator parameters or triggers.
- [Details](calls/animator/index.md)

<a id="callgameobject"></a>
### [`CallGameObject`](calls/call-game-object/index.md)

- Invoke a method on a `GameObject` or component by reflection.
- [Details](calls/call-game-object/index.md)

<a id="callstatic"></a>
### [`CallStatic`](calls/call-static/index.md)

- Invoke a static method via reflection.
- [Details](calls/call-static/index.md)

<a id="debugprint"></a>
### [`DebugPrint`](calls/debug-print/index.md)

- Log a simple message to the Unity console.
- [Details](calls/debug-print/index.md)

<a id="debugprintf"></a>
### [`DebugPrintf`](calls/debug-printf/index.md)

- Log a formatted message to the Unity console.
- [Details](calls/debug-printf/index.md)

<a id="destroycomponent"></a>
### [`DestroyComponent`](calls/destroy-component/index.md)

- Remove a component from host game object.
- [Details](calls/destroy-component/index.md)

<a id="functioncall"></a>
### [`FunctionCall`](calls/function-call/index.md)

- Call a selected function once.
- [Details](calls/function-call/index.md)

<a id="getcomponent"></a>
### [`GetComponent`](calls/get-component/index.md)

- Read component instance(s) from self/parent/children.
- [Details](calls/get-component/index.md)

<a id="getcomponentvalue"></a>
### [`GetComponentValue`](calls/get-component-value/index.md)

- [Details](calls/get-component-value/index.md)

<a id="getobjectvalue"></a>
### [`GetObjectValue`](calls/get-object-value/index.md)

<a id="instantiate"></a>
### [`Instantiate`](calls/instantiate/index.md)

<a id="objectcall"></a>
### [`ObjectCall`](calls/object-call/index.md)

<a id="playanimation"></a>
### [`PlayAnimation`](calls/play-animation/index.md)

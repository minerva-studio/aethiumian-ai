# `IsComponentOrGameObject`

## 用途
判断变量是否为 `Component` 或 `GameObject`。

## 关键输入 / 输出
- 输入：`变量`。
- 输出：bool。

## 成功 / 失败语义
- 当变量为 `Component` 或 `GameObject` 时返回 `true`。

## 重要限制
- 需要提供有效的输入变量。

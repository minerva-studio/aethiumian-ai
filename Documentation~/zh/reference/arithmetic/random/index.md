# `Random`

## 用途
生成随机标量或向量值。

## 关键输入 / 输出
- 输入：`type`, `min`, `max`, `result`, `randomSourceOverride`。
- 输出：随机化后的 `result`。

## 成功 / 失败语义
- 当输入与目标结果类型匹配时成功。

## 重要限制
- 结果类型决定输出行为（数值或向量）。

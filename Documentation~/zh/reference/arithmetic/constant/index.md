# `Constant`

## 用途
返回固定布尔值。

## 关键输入 / 输出
- 输入：`returnValue` (`bool`)。
- 输出：`bool` 返回值。

## 成功 / 失败语义
- 始终成功，并返回配置的布尔值。

## 重要限制
- 位于 `Runtime/Nodes/Flows/Constant.cs`，并继承自 `Arithmetic`。

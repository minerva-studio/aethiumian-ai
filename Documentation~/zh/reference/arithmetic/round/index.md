# `Round`

## 用途
将数值或向量输入逐分量四舍五入到最近的整数值。

## 关键输入 / 输出
- 输入：`a` (`VariableField`，数值或向量)。
- 输出：`result`，标量或向量的每个分量四舍五入到整数值。

## 成功 / 失败语义
- 输入为支持的数值或向量类型时成功。
- 输入类型不支持时失败。

## 重要限制
- 整数输入保持不变。

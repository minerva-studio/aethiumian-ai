# `Absolute`

## 用途
对数值输入计算绝对值。

## 关键输入 / 输出
- 输入：`a` (`VariableField`, `numeric`)。
- 输出：`result` (`VariableField`)，为输入的绝对值。

## 成功 / 失败语义
- 输入为有效数值时成功。
- 当输入非数值时失败。

## 重要限制
- 仅支持数值类型。

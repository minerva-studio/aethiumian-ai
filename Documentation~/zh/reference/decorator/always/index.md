# `Always`

## 用途

执行固定布尔值并返回该结果。

## 关键输入 / 输出

- 输入：`节点` (`TreeNode`), `returnValue` (`VariableField<bool>`)。
- 输出：无。

## 成功 / 失败语义

- 返回配置的 `returnValue`。

## 重要限制

- 子节点的执行结果会被忽略。

# `Condition`

## 用途
根据布尔条件在两个分支节点之间切换。

## 关键输入 / 输出
- 输入：`condition` (`TreeNode`), `trueNode` (`TreeNode`), `falseNode` (`TreeNode`)。
- 输出：无。

## 成功 / 失败语义
- 根据选中分支的返回值返回 `true` 或 `false`。

## 重要限制
- 两个分支节点都必须在树中有效且可到达。

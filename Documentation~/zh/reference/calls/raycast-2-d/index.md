# `Raycast2D`

## 用途
执行一次 2D 射线检测并输出命中结果。

## 关键输入 / 输出
- 输入：`center`, `direction`, `距离`, `layerMask`。
- 输出：`result` (`RaycastHit2D`)。

## 成功 / 失败语义
- 根据是否命中碰撞体返回。

## 重要限制
- 固定 2D 射线检测行为。

# 调用节点

## 扩展基类（不计入公开目录）

- `Call`：调用类型节点基类。
- `ObjectCallBase`：对象/组件反射调用节点的基础抽象。

## 分类节点

<a id="add-component"></a>
### [`AddComponent`](calls/add-component/index.md)
- 用途：向对象添加指定组件。

<a id="add-force"></a>
### [`AddForce`](calls/add-force/index.md)
- 用途：给当前对象添加二维力。

<a id="animator"></a>
### [`Animator`](calls/animator/index.md)
- 用途：执行该节点定义的核心行为。

<a id="call-game-object"></a>
### [`CallGameObject`](calls/call-game-object/index.md)
- 用途：执行该节点定义的核心行为。

<a id="call-static"></a>
### [`CallStatic`](calls/call-static/index.md)
- 用途：反射调用静态方法。

<a id="debug-print"></a>
### [`DebugPrint`](calls/debug-print/index.md)
- 用途：打印简单调试日志。

<a id="debug-printf"></a>
### [`DebugPrintf`](calls/debug-printf/index.md)
- 用途：按格式字符串输出日志。

<a id="destroy-component"></a>
### [`DestroyComponent`](calls/destroy-component/index.md)
- 用途：销毁当前对象上的指定组件。

<a id="function-call"></a>
### [`FunctionCall`](calls/function-call/index.md)
- 用途：调用函数引用一次。

<a id="get-component"></a>
### [`GetComponent`](calls/get-component/index.md)
- 用途：获取组件。

<a id="get-component-value"></a>
### [`GetComponentValue`](calls/get-component-value/index.md)
- 用途：读取组件字段/属性值。

<a id="get-object-value"></a>
### [`GetObjectValue`](calls/get-object-value/index.md)

<a id="instantiate"></a>
### [`Instantiate`](calls/instantiate/index.md)
- 用途：执行该节点定义的核心行为。

<a id="object-call"></a>
### [`ObjectCall`](calls/object-call/index.md)
- 用途：反射调用对象上的实例方法。

<a id="play-animation"></a>
### [`PlayAnimation`](calls/play-animation/index.md)
- 用途：立即播放动画状态。

<a id="raycast"></a>
### [`Raycast`](calls/raycast/index.md)
- 用途：执行三维射线检测。

<a id="raycast-2-d"></a>
### [`Raycast2D`](calls/raycast-2-d/index.md)
- 用途：执行二维射线检测。

<a id="set-component-value"></a>
### [`SetComponentValue`](calls/set-component-value/index.md)
- 用途：写对象组件字段/属性。

<a id="set-object-value"></a>
### [`SetObjectValue`](calls/set-object-value/index.md)
- 用途：写任意对象字段/属性。

# Documentation Demo

This project-neutral sample contains a runnable Aethiumian.AI behaviour tree and scene.

1. Open `Documentation Demo.unity`.
2. Open `Documentation Demo Behaviour Tree.asset` in **Window > Aethiumian AI > AI Editor**.
3. Enter Play Mode and open **Window > Aethiumian AI > AI Inspector**.
4. Change the runtime `TargetVisible` value to observe the alternate branch.

The graph uses `Sequence`, `Condition`, `Equals`, `Loop`, `Wait`, `Probability`, and `DebugPrint`. `ActionDelay` controls the wait duration.

# Aethiumian.AI

Aethiumian.AI is a Unity behaviour-tree-like AI runtime and editor package used by Library of Meialia.

![Aethiumian.AI graph editor](./Documentation~/assets/images/ai-editor-graph.png)

## 简介（中文）

Aethiumian.AI 是一套在 Unity 下使用的行为树式 AI 运行时与编辑系统，服务于 [Library of Meialia](https://store.steampowered.com/app/3102950/Library_of_Meialia/)，也可复用于其他项目。

## English summary

Aethiumian.AI provides runtime tree execution, node editors, variable system, and extensibility hooks for custom gameplay nodes in Unity.

## Installation summary / 安装摘要

- Package name: `com.minervagamestudio.aethiumian.ai`
- Minimum Unity: `2021.3`
- The package manifest currently declares no package dependency. The Library of Meialia integration also uses [Unity Utilities](https://github.com/minerva-studio/unity-utilities).
- Documentation site: `https://minerva-studio.github.io/aethiumian-ai/`

## Quick Start / 快速上手

1. Install from Git URL in Package Manager: `https://github.com/minerva-studio/aethiumian-ai.git`
2. Open `Window > Aethiumian AI > AI Editor`
3. Create / open a `BehaviourTreeData`, assign it to `AI.Data`
4. Play the scene and validate behavior via the AI component context menu and runtime inspector
